Mieten oder besitzen - das ist diese Woche die Frage. Meta bringt ein Frontier-nahes Modell, das lokal auf zwei Macs läuft. Google stellt sein Flaggschiff breit bereit, kündigt aber schon die Preisverdopplung an. Anthropic verkauft das Prüfen von Code als eigenes Produkt. Meta

Open Weights Muse Spark Open - läuft auf zwei Macs · 15. Oktober

Meta nennt es das fähigste US-Open-Weight-Modell: 816 Mrd. Parameter als Mixture-of-Experts, davon nur 42 Mrd. aktiv pro Token, bis 1 Mio. Tokens Kontext (Text, Bild, Video, Audio ein - Text aus). Neue Marke „Muse" statt Llama.

Der eigentliche Clou kommt mit Apple: Das Modell läuft lokal auf zwei vernetzten M5-Ultra-Mac-Studios mit zusammen rund einem Terabyte Speicher, kein Rechenzentrum nötig. Frei herunterladbar unter eigener „Muse Model License", kommerzielle Serving-Lizenz erst ab 20 Mio. $ Umsatz. In den Benchmarks nur Mittelfeld (Intelligence Index 39), aber darum geht es hier nicht.

Google · DeepMind

GAPreis steigt Gemini 4 Argon breit verfügbar · 13. Oktober

Nach einer auf Cyber-Verteidiger beschränkten Testphase ist Googles neues Flaggschiff Gemini 4 Argon nun allgemein verfügbar: über die Gemini API für Entwickler, für Unternehmen und für AI-Pro-/Ultra-Abonnenten in der Gemini-App und im AI Mode der Suche.

Der Haken steht im Kleingedruckten: Der API-Einführungspreis von 2 $ Input / 10 $ Output je Mio. Tokens verdoppelt sich nach dem 30. November. Laut Reuters hat Google zugleich Gemini 3.5 Pro nach Verzögerungen ganz gestrichen. Nach der Verknappung des Gratis-Zugangs letzte Woche zieht Google die Preis-Schraube weiter an.

Anthropic

GA Code Review für Claude Code allgemein verfügbar · 15. Oktober

Mehrere Agenten prüfen einen Pull Request parallel, ein Verifikationsschritt wirft Fehlalarme raus, die Funde werden nach Schwere sortiert an den PR gepostet. Der Check blockiert oder genehmigt nie einen Merge - er kommentiert nur. Verfügbar für Team und Enterprise auf GitHub-Repos.

Anthropics eigene Zahlen: Review-Zeit von ~20 auf 6-10 Minuten, substanzielle Review-Kommentare von 16 % auf 54 %, bei PRs über 1.000 Zeilen Funde in 84 % der Fälle. Enterprise-Orgs können 10.000 bis 50.000 $ Credits beanspruchen. Flankierend berichtet Anthropic, intern von ~2.500 auf über 30.000 gemergte Code-Änderungen pro Tag gewachsen zu sein.

OpenAI

Monetarisierung Visuelle Werbung in ChatGPT - US-Test startet

OpenAI hat ein visuelles Anzeigenformat angekündigt: Ads erscheinen neben KI-generierten Bildern, laut OpenAI klar gekennzeichnet, von den Antworten getrennt und ohne Einfluss auf sie. Der begrenzte US-Test mit ausgewählten Werbepartnern läuft diesen Monat an. Kein neues Modell in der Berichtswoche - aber ein klarer Schritt zur Monetarisierung bei über einer Milliarde Wochennutzern.

Kontext · Open-Weights-Welle

nicht primär verifiziert Offene Gewichte rücken in Frontier-Nähe

Meta war nicht allein: Reflection AI „Beam" (16.10., Apache 2.0) als 501B-MoE für Coding und Agenten, DeepSeek V4.1-Flash (17.10.) mit 552B und Live-Websuche, dazu Black Forest Labs' Bildmodell FLUX 3 Image Klein. In einer einzigen Woche landeten gleich mehrere große offene Modelle - ein Muster, kein Zufall.

Einordnung · Controller-Perspektive

Die interessante Trennlinie dieser Woche verläuft nicht zwischen den Modellen, sondern zwischen mieten und besitzen.

Google zeigt, wohin die Mietpreise laufen: erst Gratis-Modelle streichen, dann die API-Preise zum 1. Dezember verdoppeln. Meta zeigt die Gegenbewegung: ein Frontier-nahes Modell, das ohne Cloud auf zwei Rechnern unterm Schreibtisch läuft. Für die Kalkulation heißt das: Wer dauerhaft hohe Volumen fährt, sollte die Gesamtkosten einer gemieteten API gegen die Einmalinvestition in eigene Hardware rechnen - und sich den 30. November im Kalender markieren.
